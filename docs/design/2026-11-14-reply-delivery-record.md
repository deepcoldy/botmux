# 正文与附件的交付记录

正文投递成功后，在第一份附件上传前写入 pending 清单。每份文件或视频的独立 provider 结果立即追加到同一条主消息的记录；并发更新使用现有文件锁与原子替换，保留已成功结果。迟到失败不会抹掉成功回执。

记录存放在现有附件目录的应用隔离范围，身份包括应用、真实群和主消息。只记录文件显示名、类型和 provider message ID，不保存正文、凭证或本地绝对路径。quoted 先读取真实主消息并确认 chat_id，再附带该交付记录；用户按所需文件的 messageId 调用现有 quoted 下载，无需遍历整个话题。

若进程在发送后、记录前退出，状态保持 pending，表示结果未确认，不自动重发。记录写入失败独立报告，不能把已投递正文或附件变成整体失败。主消息回放保留现有跳过附件副作用的边界。尚未记录的历史回复不做推断关联。
