# 可配置反馈卡与动作扩展

状态：开发中，尚不能启用独立反馈卡或执行 Hook。

## 本次基础变更

- `feedbackPresentation` 提供 bot 默认、群规则和具体问题规则。
- 具体问题覆盖群规则；数组整体替换；同 selector 或 id 重复时报错。
- `rounds` 必须是升序、无重复的正整数；未配置默认关闭。
- 现有反馈按钮定义不复制到展示配置，后续 renderer 必须使用原 delivery 的反馈策略。
- 配置写入和重载共用规范化；直接写入无效展示规则也会拒绝。
- 宿主 Hook 注册类型和校验器约束命令参数、工作目录、作用域及秘密引用。此阶段尚未接入注册 UI 和执行器。

## 剩余交付

1. canonical 回答绑定、正式回答轮次、独立 surface 及恢复。
2. 与生产构建逻辑共用的自定义模板及安全预览。
3. 通用动作、可信回调、持久化 Hook 调度及未知结果核对。
4. Dashboard 规则、模板预览与分级 Hook 管理 UI。
5. 集成、浏览器验证、兼容性检查和独立状态机复核。

独立反馈卡不能作为新回答计入统计；预览/保存不能执行脚本；结果未知不能自动重复业务写入。默认不得改动运行中的配置、迁移共享反馈库或重启服务。

## 数据源约束

当前 `listFeedbackEvents()` 在 SQLite 和 PostgreSQL 均按 `created_at,event_id` 返回完整列表，尚无提交顺序游标。时间戳或字符串事件 ID 不能当成可靠消费高水位；后续事件接入必须先建立可恢复读取契约，不能以周期性全表扫描替代设计要求。
