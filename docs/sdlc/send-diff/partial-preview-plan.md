# 超限 diff 部分预览修订（2026-10-30T06:51:15+08:00）

## 用户要求与审批边界
超大diff继续显示部分文件/行，最多60行，用一小行灰字说明截断；不再默认完全省略内容。本轮本地实现、测试、文档与当前会话展示已完成，本次本地提交、推送及既有PR更新已获明确授权。

## 实现
- CLI通过FD读取最多2MiB+1字节，超限时解码2MiB前缀（stream模式处理末尾多字节）；finally关闭FD。保留严格正常输入检查。
- parseUnifiedDiff增加仅供明确前缀模式的EOF容忍：尾部header未完整则不展示该文件，hunk剩余行数只能在这个模式保留；其他非法内容仍拒绝。标记尾行内容截断。
- 卡片继续用原折叠面板，最多60行；超预算降低实际展示行/文件数，灰字说明实际展示数，长行保留前段并标记截断。
- 部分解析的标题计数只统计展示行，statsScope=preview，完整输入仍statsScope=full；未知全量省略文件数为null。
- 不新建生产模块，保留H1/H2和错误收口修复。
