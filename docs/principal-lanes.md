# 群内真人独立 lane

Botmux 默认仍是“全群共用一个会话”。当群成员需要共享上下文、文件和同一项任务时，应保持默认模式。

对同一个 Bot 开启 Dashboard「全局设置 → 跨身份打断隔离（XPI）」后，普通群聊中的每位真人会获得独立的 CLI 上下文和 git worktree。该模式适合多人在同一台机器上分别处理完全独立的任务；它不会隐藏群消息，所有提问和回复仍在同一个群里公开可见。

## 协作语义

- 不引用其他任务的普通消息，进入发送者自己的 lane，不会打断别人正在执行的任务。
- 引用别人正在执行的任务时，消息进入建议/确认流程；任务发起人可以采纳或拒绝。
- 因此成员仍可围绕同一任务协作，但独立 lane 不共享 CLI 记忆和工作区文件。需要持续共用上下文与文件时，应关闭 XPI，使用默认共享会话。
- XPI 默认关闭，Dashboard 改动从下一条消息起生效，无需重启。

## lane 生命周期

发送 `/lane status` 可查看本人 lane 的分支、worktree、未提交文件和相对主分支的提交数。

发送 `/lane close` 会先执行安全检查并返回一次性确认命令。确认关闭时：

1. 有未提交文件、正在运行的 turn、排队任务或未决工作区 ticket 时拒绝关闭，避免丢失工作；
2. 有已提交成果时，先把 lane 分支推送到远端；推送失败则保留会话和 worktree；
3. 会话成功关闭并撤销 lane 的持久化路由后，再回收 worktree；
4. worktree 删除失败时保存清理任务，可用返回的 `/cleanup-wt <id>` 重试。

关闭不会自动合并或删除分支。远端分支是代码交付入口，仍需按团队流程 review、建 PR 或合并。
