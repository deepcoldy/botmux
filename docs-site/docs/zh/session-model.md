# 会话与话题模型

理解 botmux 的关键是搞清「一条消息落到哪个会话」——**「为什么每次 @ 都像新开、丢了上下文」「新群怎么拉到历史」这类困惑，根子都在这**。

**适用**：搞不清消息去了哪个会话、想控制新开 vs 复用、或配群内权限时。

## 三种群形态

| 形态 | 行为 |
|------|------|
| **话题群（THREAD）** | 每个新话题 = 一个独立 CLI 会话。同一话题内的消息进同一会话，不同话题互相隔离。最推荐。 |
| **普通群（DEFAULT）** | 顶层 @ 默认平铺复用整群 session，用户自己开的原生话题各自独立（`chat-topic`）。可用群级回复模式改成全平铺、话题展示共享上下文或每次新话题。`/t <内容>` 始终可强制新开话题。 |
| **私聊** | 直接和机器人开聊，相当于一个长期会话。 |

> 关闭「任务执行时显示状态卡片」后，`/t <内容>` 仍会先产生一条可见的话题回复，确保飞书立即展开 thread；reaction 只作为进度提示。

## 普通群的群级回复模式

| 模式 | 顶层回复 | 会话与上下文 |
|------|------|------|
| `chat` | 群顶层平铺 | 整群共享一个 session，原生话题也折叠回该 session |
| `chat-topic` | 群顶层平铺 | 顶层共享 session，原生话题各自独立（默认） |
| `topic` / `shared` | 触发消息下的话题 | 只改展示位置，整群仍共享一个 session |
| `new-topic` | 触发消息下的新话题 | 每次顶层 @ 都是独立 session 和上下文 |

有效值的优先级是“当前 bot 的群级覆盖 > 当前 bot 的 `regularGroupReplyMode` > `chat-topic`”。例如 Agent1 默认为 `chat`，仅 A 群覆盖为 `new-topic`，则其他群都继承 `chat`。在 Dashboard 选“继承 Bot 默认”会清除 A 群的覆盖；此后 Agent1 默认值改变时，A 群会继续跟随。显式模式则不会因 Bot 默认值改变而漂移。话题群不参与这个优先级，始终在当前话题内独立回复。

## Oncall 群 & chat-scope 群

- **Oncall 群**：`/oncall bind <path>` 把整个群锚定到一个项目目录，跳过仓库选择，群内任何成员 @ 即问即答。见 [Oncall 模式](/oncall)。
- **chat-scope 群**：`/group <群名>` 一键新建一个群，整个群作为一个独立会话。

## 会话状态机

流式卡片顶部的状态指示：

- 🟡 **启动中** — worker 正在拉起 CLI 进程
- 🔵 **工作中** — CLI 正在思考/执行，输出实时刷新
- 🟢 **就绪** — CLI 空闲，等你的下一条消息

每次回复创建**新的**流式卡片，上一轮卡片冻结在最后状态，便于回看历史。

## 权限模型（三层）

| 层级 | 能力 | 由谁控制 |
|------|------|---------|
| **对话权（canTalk）** | 提问、查日志、读代码 | `allowedChatGroups`（群内全员）/ `globalGrants`（全局名单）/ `/grant` |
| **操作权（canOperate）** | 切目录 `/cd`、`/restart`、`/close`、点卡片按钮 | `allowedUsers`（owner 名单） |
| **owner 专属** | `/grant` `/revoke` 授权他人 | owner |

这套分层让你能放心把机器人拉进值班群：所有人能问，但只有 owner 能改会话状态，外部成员误点也不会把会话搞乱。

## 常见困惑

- **「每次 @ 都像重新开始、丢上下文」**：在**话题群**里，不同话题是不同会话——你以为在追问，其实开了新话题 = 新会话。想接着聊就在**同一条话题**里回复；确实要复用同一会话见下。
- **新群 / 新话题拉不到之前的聊天**：新会话默认从干净状态起。要它读群历史，直接说「看下之前的聊天记录」（需机器人有群消息读取权限，见 [FAQ](/faq)）。
- **想换底层 CLI 又保留上下文**：目前**做不到跨 CLI 无损热切**——原生会话历史不会翻译到另一种 CLI。要换 CLI 就开新 bot / 新 session，并让原 bot 输出一份 handoff 摘要交接。（[`/relay`](/relay) 是把**同一个会话**整体搬到另一个群、不换 CLI；[`/adopt`](/adopt) 是把本机已有 tmux/zellij / 可恢复会话接进飞书，也不换 CLI。）
