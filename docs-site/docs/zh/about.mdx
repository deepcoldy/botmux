## 安装与升级

**推荐：一键安装脚本**（自包含二进制，不需要装 Node）：

```bash
curl -fsSL https://raw.githubusercontent.com/deepcoldy/botmux/master/install.sh | sh
```

支持 Linux 和 macOS，x64 / arm64 都行；Alpine 这类 musl 系统会自动选对应版本。Windows 请在 WSL2 里安装。

**备选：npm 安装**：

```bash
npm install -g botmux
```

这一步需要 Node ≥ 22（npm 本身的要求）。npm 包里是同一个自包含程序，装好后运行不依赖 Node。

**升级**：执行 `botmux update`（`botmux upgrade` 同义），再 `botmux restart` 让新版本生效。v3.18.0 之前的老版本请重跑上面的 curl 命令，原因见 [FAQ · 怎么升级？](/faq#怎么升级)。

第一次上手看 [5 分钟快速接入](/quickstart)，遇到问题先翻 [常见问题](/faq)。
