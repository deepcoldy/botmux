# 驾驶舱（Agent 工作台）

<video src="img/video-v7-dashboard.mp4" controls preload="metadata" style="width:100%;border-radius:8px"></video>

驾驶舱是 [Dashboard](/dashboard) 里专门用来**同时盯多个 AI 会话**的界面：左边是这台机器上所有会话的列表，右边是选中会话的终端。哪个会话干完活了、哪个卡住等你处理，一眼就能看到。

飞书 `/dashboard` 卡片上的「打开工作台」按钮、`botmux dashboard` 打印的 `工作台: …` 链接，打开的都是它。

![驾驶舱全貌：左侧会话列表，右侧终端](/img/workbench-overview.png)

适合这些场景：

- 同时开着好几个话题，想知道**谁回完了、谁在等你**，不用挨个翻飞书群。
- 想看某个会话的**实时终端**，必要时直接在终端里敲键盘。
- 在手机上随手看一眼进度。

## 怎么打开

| 入口 | 怎么做 | 说明 |
|---|---|---|
| Dashboard 侧边栏 | 点「驾驶舱」 | 带 Dashboard 的顶栏和侧边栏 |
| 飞书卡片 | 管理员在飞书里发 `/dashboard`，机器人私信你一张总览卡，点「打开工作台」 | 电脑上在飞书里开一个标签页（可右键固定），手机上打开网页 |
| 命令行 | 在机器上跑 `botmux dashboard`，复制 `工作台: …` 那一行 | 适合收藏成书签 |
| 常驻链接 | 在驾驶舱的外观菜单里点「常驻链接」，复制 | 见下文「长期入口」 |

从卡片、命令行、常驻链接这类**直达入口**打开时，驾驶舱是整屏显示的，不带 Dashboard 的侧边栏。

## 看会话列表

列表默认按状态分三组：

| 分组 | 里面是什么 |
|---|---|
| 待你处理 | 需要你动手的会话（见下表），以及机器人刚回完、你还没点开看的会话（标「有新回复」） |
| 进行中 | 还活着的会话 |
| 最近 | 已经结束或休眠的会话 |

「待你处理」的常见原因：

| 行上显示 | 意思 |
|---|---|
| 有新回复 | 机器人干完活了，你还没看 |
| Agent 请求协助 | AI 主动喊你 |
| 需要选择仓库 | 会话还没选工作目录 |
| 终端有待确认的提示 | CLI 弹出了确认框，等你选 |
| 待启动 | 在排队，还没真正启动 |
| 用量已达上限 | CLI 额度用完了 |

点开一个会话就算看过，「有新回复」随之消失。

常用操作：

- **换分组方式**：列表顶部的下拉框，可选状态、机器人、会话位置、类型、CLI、活跃时间、Worktree。选过之后会记住。
- **搜索**：按 `/` 跳到搜索框。
- **键盘上下选**：`j` / `k` 或方向键。
- **调宽度 / 收起列表**：拖动列表右边的竖条调宽度，点 `«` 收起。

每一行右侧有几个快捷按钮：

| 按钮 | 作用 |
|---|---|
| 聊天 | 在飞书里打开这个会话所在的聊天 |
| 定位 | 只有话题会话有。让机器人在原话题里 @ 你一下，点飞书通知就能回到话题。发一次后 30 秒内不能再点 |
| 跳转 | 只有话题会话、且能拿到原话题链接时才出现。直接跳到飞书里的原话题 |
| 终端 | 在右侧打开这个会话的终端（一般是只读打开，见下文） |

## 看终端、直接输入

点会话行的「终端」，右侧就是这个会话的实时终端，和 [Web 终端](/web-terminal) 看到的是同一个画面。

- 默认是**只读**：只能看，不会误输入。
- 想在终端里打字：点终端标题栏的「接管输入」。接管后标题栏会显示到期时间，用完点「释放输入」还回去。
- 有的身份没有接管权限，这时不会显示「接管输入」按钮，提示里会写「当前身份不可接管输入」。
- 通过中心化平台以所有者身份登录时，终端打开就能直接输入，提示里会写「可直接输入」，不用再接管。
- 「新标签页打开」可以把终端单独开在一个浏览器标签里。
- 「关闭终端 ✕」收起终端面板。

想像在飞书里那样和 AI 聊天，点会话行的「聊天」回到飞书即可。驾驶舱本身不重复做一个聊天框。

## 在手机上用

屏幕较窄时（比如手机），驾驶舱会变成**一页一页**的形式：

1. 先看到会话列表。
2. 点一个会话，进入它的详情页，顶部能切换「终端」「信息」；会话用 `botmux preview <端口>` 登记过网页预览的，还会多一个「网页」。
3. 左上角「‹ 会话列表」返回。

![手机上的会话列表](/img/workbench-mobile-list.png)

手机上的终端默认是只读视图，要输入请在电脑上操作（个别身份在手机上也能直接输入，终端提示里会写明）。

想把驾驶舱放到手机桌面：用手机浏览器打开后，选「添加到主屏幕」，之后从桌面图标直接进入会话列表。

### 会话坞（精简版）

会话坞是驾驶舱的窄条版本，适合嵌在侧边栏这类窄位置，地址是 `<你的 Dashboard 地址>/workbench/dock`。它只有会话列表，加上「打开完整工作台」「打开聊天」「终端链接」「网页链接」几个按钮，终端和网页要到完整工作台或新标签里看。

## 外观

电脑上点右上角的 `⋯` →「外观」；手机上点列表顶部的 `◐`。

![外观菜单](/img/workbench-appearance-menu.png)

| 选项 | 可选值 | 说明 |
|---|---|---|
| 主题 | 墨黑、蓝灰、石墨、冷白 | 墨黑 / 蓝灰 / 石墨是三套深色；冷白是浅色 |
| 明暗模式 | 跟随系统、浅色、深色 | 选浅色时总是用冷白；选深色时用你挑的那套深色主题；跟随系统时两者之间自动切 |
| 终端渲染 | 阅读、经典 | 阅读：颜色更柔和、行距更大，久看不累；经典：终端原本的样子 |

默认是蓝灰 + 经典。终端标题栏上也有「阅读 / 经典」切换，就近可点。

外观设置保存在当前浏览器里，换一台设备或换一个浏览器要重新选。第一次打开驾驶舱时，明暗模式沿用 Dashboard 的设置。

## 长期入口：常驻链接

想要一条**收藏进书签、一直能用**的驾驶舱链接：

1. 用 `botmux dashboard` 打印的链接登录 Dashboard（这是本机管理员身份）。
2. 打开驾驶舱，点 `⋯` →「常驻链接」（手机上在 `◐` 弹出的面板里）。
3. 点「复制」，收藏到浏览器书签。

几点说明：

- 「常驻链接」**只对本机管理员显示**。通过中心化平台或飞书免登进来的身份看不到这一项。
- 这条链接和飞书卡片上「打开工作台」按钮的链接一样，都带着 Dashboard 的长期 token：不会过期，`botmux restart` 后也能用，电脑和手机都能反复打开。
- 怀疑链接泄漏了，在机器上执行 `botmux dashboard rotate`。token 一换，所有旧链接（包括已发出去的卡片按钮）立刻失效，之后重新取一次常驻链接即可。
- 如果卡片下方的小字写着「暂时读不到 Dashboard 凭证」，说明这次按钮链接不带登录信息，打开后需要自己登录。

## 手机打不开？用自助诊断页

手机上驾驶舱空白、终端一直不出来，而电脑上一切正常时，在手机浏览器里打开：

```
<你的 Dashboard 地址>/workbench-doctor
```

这个页面**不需要登录**，打开后会自动逐项检查，每项最多等 8 秒：

| 检查项 | 能看出什么 |
|---|---|
| 设备信息、页面地址、设备时间 | 用的是什么浏览器、打开的是哪个地址 |
| 服务版本 | 和电脑上看到的版本不一致，说明手机吃了旧缓存 |
| 会话列表接口 | 失败说明登录状态（Cookie）没带上 |
| 终端链接、终端页面 | 终端地址能不能拿到、从手机的网络能不能访问 |
| 实时连接（两条链路） | 终端画面要用的 WebSocket 连接能不能建立 |

等页面跑完，截一张图发给机器人或维护者，就能判断是网络、登录状态还是旧缓存的问题。页面不会显示任何 token 或密钥，截图可以放心发。

想诊断某一个具体会话，在地址后面加 `?session=<会话 ID>`。

## 常见问题

**手机上提示「终端实时连接未建立」？**
iOS 的飞书内置浏览器常会拦下非加密的实时连接。点飞书右上角 `⋯`，选「在浏览器打开」，用系统浏览器再试；或者在电脑上看。

**会话行上没有「定位」「跳转」？**
这两个按钮只对话题会话出现；「跳转」还需要机器人拿得到原话题的链接。群会话和单聊只有「聊天」和「终端」。

**选中的会话显示「会话不存在」？**
这个会话已经结束或被清理了，从列表里另选一个即可。

**为什么我看不到「常驻链接」？**
只有用 `botmux dashboard` 打印的链接（或卡片按钮）登录的本机管理员才能看到。
