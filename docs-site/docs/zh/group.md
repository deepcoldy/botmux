# 一键新建会话群

<video src="img/video-v4-multibot.mp4" controls preload="metadata" style="width:100%;border-radius:8px"></video>

想给一个项目或任务单独开一个干净的群？发 `/group <群名>`（简写 `/g`）就行。机器人会帮你：

1. 新建一个飞书群，把你拉进去；
2. 把群主转给你；
3. 回你一张带加群链接的卡片。

进群直接和机器人说话即可。**整个群就是一个独立的 CLI 会话**（会话 = 一个正在运行的 AI 编程 CLI 进程，比如 Claude Code、Codex）。

```bash
/g 卡片竞态 bug
```

回复大致是：

```text
✅ 已新建群「卡片竞态 bug」
👉 <加群链接>

直接在新群里开聊就行，整个群是一个独立的 CLI 会话。
```

> 建好群后**不会自动开会话**。你在新群里发出第一条消息时，会话才启动。

botmux 里有两种「会话群」，本页都会讲到：

| | `/g` 建的群 | 私聊专属群 |
| --- | --- | --- |
| 怎么来的 | 你在任意聊天里发 `/g` | 开启后，私聊机器人的每条新消息自动建一个群 |
| 适合 | 手动为某个项目 / 任务开协作空间，可拉多个机器人 | 想让每次私聊提问都有独立的群，方便回看 |
| 详见 | 下文「用 `/g` 建群」 | 下文「私聊专属群」 |

## 用 `/g` 建群

### 群名和头像

- **写了群名**：用你的群名，之后不会再改。
- **不写群名**（只发 `/g`）：先用占位名「新会话 MM/DD HH:mm」。你在新群里发出第一条有内容的消息后，机器人会根据内容总结一个不超过 12 字的标题，自动改群名。
- **头像**：默认是 botmux logo 加渐变底色（十种配色里按群固定选一种）。加 `--avatar name` 改用群名文字头像，`--avatar off` 保留飞书默认头像。

![群名文字头像示例](/img/group-name-avatar.png)
*`--avatar name` 生成的群名文字头像*

自动改名的几点说明：

- 斜杠命令、只有图片/附件的消息、机器人发的消息，不作为起名依据。
- 你自己先手动改了群名，就以你的为准。
- 多个机器人的群里，只有建群的那个机器人负责起名。
- 起名失败时保留占位名，之后你再发消息时重试（两次重试分别至少间隔 30 秒、2 分钟），最多三轮。
- AI 起名需要在本机单独跑一次 CLI，所以只在这些情况下生效：CLI 是 Claude Code、Codex、TRAE CLI（traex）、OpenCode、Antigravity、Grok、Pi 或 oh-my-pi；机器人没开文件沙盒；本机没启用设备凭证隔离；不是自定义启动方式；Codex 没用私有登录或实例池。其他情况保留占位名。

### 带上多个机器人

在命令里 @ 几个机器人，它们会**一起被拉进新群**，由第一个被 @ 的机器人负责建群：

```bash
@Claude @Codex /g review 群授权
```

回复里会列出「🤖 群内机器人：Claude、Codex」。进群后 @ 谁，谁就干活。

不想每次都 @，也可以用 `--agents` 按名字或 app ID 指定，机器人不必在当前群里，但要在本机 `bots.json` 里配置并已连上飞书：

```bash
/g 项目讨论 --agents Review,Build,Check
```

名字不区分大小写。名字找不到或重名时会在建群前报错，重名请改用 app ID。

> 如果你在本机设置了[决策看板的管家](/decision-board)，并且开了「拉新群时带上管家」，新群里有管家的 owner 时，管家也会被一起拉进来（不发言、不开会话）。只有你和一个机器人的群默认不带。

### 全部参数

| 参数 | 作用 |
| --- | --- |
| `--agents A,B` | 额外邀请这些机器人（显示名或 app ID，逗号分隔）；会替换默认名单 |
| `--no-agents` | 忽略默认邀请名单 |
| `--tag <分组名>` | 把新群放进你飞书侧边栏的某个消息分组（最多 60 字） |
| `--no-tag` | 忽略默认分组 |
| `--avatar logo\|name\|off` | 头像：渐变 logo（默认）/ 群名文字 / 飞书默认 |
| `--role-profile <id>` | 建群后给群里的机器人套用一套[角色配置集](/roles) |
| `--` | 选项结束符：它后面的内容都算群名，适合群名里本身带 `--tag` 这类字样 |

```bash
/g 项目讨论 --agents Review,Build --tag 项目群 --avatar name
/g Project work --tag "Project work"
/g --avatar off
```

补充说明：

- 选项值可以用 `--tag=项目群` 或 `--tag 项目群`，带空格用引号。
- 缺值、值不合法、同一选项写两次，都会在建群前报错，不会建出一个错的群。
- 不认识的 `--xxx` 不报错，会原样留在群名里。
- `--tag` 是**你个人侧边栏的消息分组**，不是企业共享的群标签。第一次用需要授权：在和该机器人的聊天里发 `/login tags`，点链接确认。没授权时群照样建好，回执里会提示。
- 邀请机器人、设置分组或头像失败，都只在回执里单独提示，不影响已建好的群。

### 套用角色配置集

如果你在[角色配置集（Role Profile）](/roles)里维护了一套可复用的协作人设，建群时加 `--role-profile`：

```bash
@Claude @Codex /g --role-profile collab-main review 群授权
```

建群成功后，建群的机器人先给自己套上对应角色，再在新群里发一条 `@Codex /role profile apply collab-main --quiet`，让其他机器人各自套用。某个机器人在配置集里没有对应条目也没关系，它会继续用默认角色。

### 给机器人设默认值

如果团队总是同一组机器人、同一个分组，可以给机器人配默认值，以后只发 `/g` 就行。在对应机器人的 `bots.json` 条目里写：

```json
{
  "groupCreation": {
    "agents": ["cli_review_app", "cli_build_app"],
    "tag": "项目群",
    "avatar": "name"
  }
}
```

也可以在飞书里发 `/botconfig set groupCreation <JSON>` 修改，`/botconfig unset groupCreation` 恢复默认。

- 命令里写的参数优先于默认值。
- 配了默认名单后，只 @ 其中一个机器人发 `/g`，也会把整组机器人都拉进来（自动去重）。
- `--no-agents`、`--no-tag`、`--avatar off` 只去掉默认值，不会踢掉你明确 @ 的机器人。
- 没配 `groupCreation` 也没传参数时，只有当前机器人和你 @ 的机器人入群。

## 在 Dashboard 里建群

不想敲命令的话，打开 `botmux dashboard` 的 **群组管理** 页，点「新建群聊」：

- 勾选要拉进群的机器人（Dashboard 会自动选一个在线的机器人来建群）；
- 填群名；
- 可选「绑定目录」：新话题直接在这个目录启动 CLI，不再弹选仓卡片；
- 可选飞书标签（侧边栏消息分组）。

已有的群可以点「**复制为新群**」：自动预选源群里的机器人和绑定目录，还能勾选「同时复制群角色」。

![Dashboard 复制为新群](/img/groups-clone-chat.png)
*「复制为新群」：预选源群的机器人、绑定目录，可选复制群角色*

点某个群的「管理」打开详情，「退群 / 解散」页签里可以让选中的机器人退群，或解散群聊。解散只在群里的机器人是群主时才会成功，否则建议让机器人退群。

![Dashboard 退群与解散](/img/groups-manage-danger.png)
*群详情的「退群 / 解散」页签*

群组页顶部可以在「普通群 / 会话群」之间切换，会话群列表默认按最近活跃排序，也可改按创建时间。更多见 [Dashboard 管控面](/dashboard)。

## 私聊专属群

开启后，你私聊机器人发的**每条新消息**，都会自动建一个只有你和这个机器人的群来承载这次对话，私聊里会收到一条带群链接的回执。

### 怎么开启

两种方式任选：

- Dashboard → **Bot 配置** → 会话 → 会话模式 → 私聊选「**每条消息建专属群**」；
- 在飞书里发 `/botconfig set p2pMode group`（`/botconfig unset p2pMode` 改回默认的「连续单聊」）。

会话 `/close` 之后，群会保留；再在群里发消息会开一个新会话，想接着之前的会话用 `/resume`。

### 群名怎么起

私聊选了「每条消息建专属群」后，下方会多出 **专属群命名方式**，在这里选：

| 选项 | 效果 |
| --- | --- |
| AI 摘要（默认） | 先用首条消息的截断内容占位，再生成一个简短标题改群名 |
| 复用 Agent 会话标题 | 直接用 CLI 自己给会话起的标题，不额外调用模型；标题还没出来时保留占位名 |
| 仅截断原文 | 只用首条消息的截断内容当群名，不再改 |

也可以写在对应机器人的 `bots.json` 里：

```json
{
  "sessionGroup": {
    "naming": { "mode": "session-title", "maxLen": 12 }
  }
}
```

`mode` 可选 `ai-summary` / `session-title` / `truncate`，`maxLen` 是标题最大字数（默认 12）。

几点说明：

- 群名只自动起一次，之后会话标题再变也不跟着改；你手动改过群名就不会被覆盖。
- 「复用 Agent 会话标题」认 Codex 自己的会话标题，以及通过 botmux 改名发布的标题（包括 Agent 自己改名、你在 Dashboard 或会话里改名）。
- Codex 做 AI 摘要时用的是隔离的轻量调用：固定 low 推理，不加载你的 hooks、插件、MCP 和项目指令，只沿用登录凭证和模型网关设置。可在「**摘要模型（Codex）**」填一个账号可用的轻量模型（bots.json 里是 `naming.model`），留空沿用机器人的模型。这个设置只影响起群名，不影响对话。

### 关闭后切换标签

专属群默认会放进你侧边栏的一个消息分组（如「XX会话」）。想让关掉的会话自动挪到另一个分组（比如「已关闭」），在 Dashboard「Bot 配置 → 会话 → 会话模式 → 私聊」下方的 **关闭后标签名** 里填一个名字（私聊选了「每条消息建专属群」才会显示）。留空就不切换。

对应的 `bots.json` 写法：

```json
{
  "p2pMode": "group",
  "sessionGroup": {
    "tag": {
      "mode": "feed-group",
      "name": "进行中",
      "closedName": "已关闭"
    }
  }
}
```

规则：

- 只有 `/close`（或关闭卡片上的按钮）**成功关闭**后才会切换。`/stop`、关闭失败、崩溃、后台清理都不会触发。
- 先加入新分组，再从原分组移出；分组不存在会自动创建，同名会复用。群和聊天记录都不受影响。
- 只支持个人消息分组（`feed-group`），用的是建群用户的授权；没授权时发 `/login tags` 补上。
- 切换在后台进行，失败会单独提示。
- 恢复会话不会自动移回原分组；清空「关闭后标签名」即可关掉这个功能，已有的群不会被批量迁移。

### 解散专属群：`/dismiss`

想把整个群也删掉？在专属群顶层发 `/dismiss`。机器人会回一张确认卡片，列出：

1. 要关闭的本群会话（包括本机其他机器人在这个群里的会话）；
2. 解散这个飞书群（所有成员都看不到了，不可撤销）；
3. 移除会话群登记（之后恢复这些会话也不会重建原群）。

点「**确认解散**」后执行。成功后群直接消失，结果通过私聊卡片通知你；卡片上还会列出这些会话用过的 worktree，可以一键清理（等同 `git worktree remove --force`，未提交的改动会丢失，分支和已提交内容保留）。不点就一直保留。

限制和注意：

- 只有建群的人本人、并且有机器人操作权限才能执行。
- 机器人需要是群主，或是建群者并有 `im:chat:operate_as_owner` 权限。
- 在专属群里只能在群顶层发，子话题里不支持；私聊不支持。普通群见下文。
- 以下情况会停下、不解散群，并在群里说明原因：群里有 `/adopt` 接入的共享会话（先 `/detach`）、本机其他机器人不在线、会话没能安全关闭、确认期间又出现了新会话。
- 解散失败时，已关闭的会话保持关闭，可以再发一次 `/dismiss` 重试。
- 代码和 worktree 默认不删。只想结束会话、保留群聊，用 `/close`。

#### 普通群和话题群

不是从私聊开出来的群（普通群、话题群）也能发 `/dismiss`，在任何话题里发都行，但要同时满足：

- 发送人有机器人操作权限；
- 机器人是群主，并且群里只有它一个机器人。飞书没法事先确认其它情况下能不能解散，所以不满足时机器人直接回复没有权限，一个会话都不关。

确认卡片列出本群里本机所有机器人的会话（话题群里每个话题的会话都在内），并说明会解散整个群、群里所有人都受影响。确认后先关闭这些会话，全部关干净才解散群，结果同样私聊通知你。中途停下的情况和上面一样。
