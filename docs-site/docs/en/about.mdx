## Install & upgrade

**Recommended: one-line install script** (self-contained binary, no Node needed):

```bash
curl -fsSL https://raw.githubusercontent.com/deepcoldy/botmux/master/install.sh | sh
```

Works on Linux and macOS, x64 or arm64; musl systems such as Alpine get the matching build automatically. On Windows, install inside WSL2.

**Alternative: npm**:

```bash
npm install -g botmux
```

This step needs Node ≥ 22 (an npm requirement). The npm package contains the same self-contained program, so running it doesn't need Node.

**Upgrade**: run `botmux update` (`botmux upgrade` is the same), then `botmux restart` to apply it. On releases older than v3.18.0, rerun the curl command above instead; see [FAQ · How do I upgrade?](/en/faq#how-do-i-upgrade) for why.

New here? Start with the [5-minute quickstart](/en/quickstart); stuck? Check the [FAQ](/en/faq).
